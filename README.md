# DeepX – Deepfake Video/Face Detection

## 📌 Overview
DeepX is an AI-based system designed to detect deepfake videos by analyzing facial frames and temporal inconsistencies using deep learning models.

## 🚀 Features
- Deepfake detection using CNN-LSTM architecture
- Frame-level facial extraction
- Explainability using Grad-CAM heatmaps
- User-friendly frontend for video upload and prediction

## 🛠️ Tech Stack
- Python, TensorFlow, Keras
- OpenCV, MTCNN
- HTML, CSS, JavaScript
- Tailwind CSS
